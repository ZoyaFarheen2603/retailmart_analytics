# 📊 PostgreSQL Retail Analytics Platform

A PostgreSQL-based retail analytics project that transforms raw retail data into meaningful business insights using advanced SQL techniques and an interactive dashboard.

## 🚀 Features

- Sales, Customer, Product, Store, Operations, and Marketing Analytics
- 25+ SQL Views and 10 Materialized Views
- KPI Reporting and Business Insights
- JSON Export Functions for Dashboard Integration
- Data Quality Validation and Performance Optimization
- Interactive Dashboard with HTML, CSS, JavaScript, and Chart.js

## 🛠️ Technologies Used

- PostgreSQL
- SQL
- HTML
- CSS
- JavaScript
- Chart.js

## 📈 Key Analytics

- Sales Performance
- Customer Lifetime Value (CLV)
- RFM Analysis
- Product Performance
- Store Performance
- Inventory Analysis
- Marketing & Campaign Analytics

## ▶️ How to Run

1. Create the PostgreSQL database.
2. Execute the SQL scripts to create the analytics schema, views, and materialized views.
3. Export JSON data.
4. Open the dashboard in a web browser.
